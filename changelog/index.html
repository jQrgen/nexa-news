Changelog

Changes to the Nexa News site itself: new pages, sections and source types. Newest first. Daily news items are not listed here.

3 Oct 2026: Independent coverage first

  • The front page now opens on independent coverage; official channels moved to a side box and a filter.
  • New independent sources: Hacker News (Algolia API), CoinDesk, Cointelegraph, The Block, Decrypt, Bitcoin.com News, dev.to and GitHub repository search.
  • Sharper news-search queries that leave out other companies called Nexa.
  • Support for third-party YouTube videos through the official YouTube Data API, shown as plain links with a locally served thumbnail and no embedded player (switched on once an API key is set).
  • GitHub repositories that call themselves 'official' are flagged for the editor.

3 Oct 2026: Nexa News launches

  • Feed of public Nexa news, forum posts, articles and releases, with filters by platform and by official or independent coverage.
  • Release timeline from the public GitLab projects (Nexa full node, Rostrum, libnexakotlin, libnexa-js, Wally Wallet, Otoplo).
  • Sources page listing every source, how it is read and whether it works.
  • About page with the disclosure, how the site works and the editorial policy.
  • Office screen mode for a TV or monitor, portrait or landscape.
  • Changelog page (this page).
